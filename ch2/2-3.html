2.3 Объектная модель: менеджеры, ссылки, объекты, запись

Цель: без подсказок написать код, который находит товар, меняет его и записывает. Это основа почти любой рабочей задачи. Время: 1 день. Застрял больше 30 минут — пиши. Git: ветка feature/ch2-t3-obektnaya-model.

1. Что это, зачем, где найти

Представь картотеку на складе:

В жизни В 1С Что можно
Кладовщик у картотеки Менеджер Справочники.Товары Найти карточку или завести новую
Номер карточки Ссылка Только читать
Карточка на столе Объект Менять
Вернуть карточку в ящик Записать() Сохранить изменения в базе

Зачем: любое изменение данных из кода идёт по цепочке менеджер → ссылка → объект → Записать().

Где что лежит:

  • EDT, навигатор → «Справочники» → «Товары»: описание справочника и его реквизиты (Цена).
  • 1С:Предприятие: сами товары с ценами.
  • Код: только в процедурах &НаСервере — база доступна только на сервере.

Справочник и документ: в чём разница

Справочник — «что существует». Список вещей: товары, склады, контрагенты. Карточка «Мышь» знает, что такой товар есть и сколько он стоит, но не знает, сколько мышей на складе.

Документ — «что произошло». Событие с датой: «19 октября пришло 10 мышей и 2 ноутбука». Как бумажная накладная.

Справочник Документ
Отвечает на вопрос Что это? Что, когда и сколько произошло?
Пример Товар «Мышь», цена 500 Приход 10 мышей 19 октября
Дата Нет Есть, обязательно
Табличная часть Редко: свойства самой вещи Обычно: какие товары и сколько в этой операции
Создать кодом СоздатьЭлемент() СоздатьДокумент()

В табличной части документа лежат не новые товары, а ссылки на товары из справочника плюс количество и цена в этой операции. Мышь в справочнике одна, а приходов с ней может быть сотня.

Зачем документы: из них считаются остатки и обороты — приходы минус расходы дают остаток на складе. Как документ превращается в остатки (проведение и регистры) — глава 5.

3. Ловушки

  1. Не нашёл — это пустая ссылка, а не Неопределено. Проверяй Пустая().
  2. НайтиПоНаименованию без Истина ищет по началу: «Мо» найдёт «Монитор». Всегда пиши Истина.
  3. Через ссылку менять нельзя: Мышь.Цена = 600 — ошибка. Только через объект. И без Записать() изменения пропадут.
  4. Запись из кода не проверяет заполнение. Пустой товар запишется. Нужна проверка — вызывай Объект.ПроверитьЗаполнение().

4. Практика А (30–60 минут)

Процедуры &НаСервере в области Задания Песочницы.

А1. Товары и цены

  1. Создай товары: Ноутбук — 60 000, Мышь — 500, Монитор — 15 000. Перед созданием ищи точным поиском: если товар есть — выведи «уже есть» и не создавай. Запусти дважды — дублей быть не должно.
  2. Найди «Мышь» и подними цену на 10% через объект.
  3. Выведи все товары с ценами через выборку.

Контроль: Мышь — 550.

А2. Документ

Создай «Приход товара» с двумя строками: Ноутбук × 2 и Мышь × 10, цену бери из товара через ссылку. Запиши, выведи номер и количество строк. Открой документ в 1С и проверь.

5. Практика Б — проект

Создай общий модуль РаботаСТоварами, тип «Серверный модуль». Функции в области ПрограммныйИнтерфейс, с Экспорт, Знач и описанием.

Б1. НайтиИлиСоздатьТовар(Наименование, Цена = 0) → СправочникСсылка.Товары

  • убрать пробелы по краям наименования;
  • пустое — вернуть Справочники.Товары.ПустаяСсылка();
  • нашёл точным поиском — вернуть ссылку, ничего не менять;
  • не нашёл — создать, записать, вернуть ссылку.

Б2. УстановитьЦену(Товар, НоваяЦена) → Булево

  • пустая ссылка — Ложь;
  • цена уже такая — Ложь, не записывать;
  • иначе изменить, записать, вернуть Истина.

Б3. СоздатьПриходТовара(СтрокиДокумента, Комментарий = "") → ДокументСсылка.ПриходТовара

  • СтрокиДокумента — массив структур Товар, Количество, Цена;
  • пустой массив — пустая ссылка документа;
  • иначе создать документ, строки заполнить через ЗаполнитьЗначенияСвойств, записать, вернуть ссылку.

Б4. Тесты — процедура ТестыРаботыСТоварами() в области Тесты:

Проверка Ожидается
НайтиИлиСоздатьТовар("Тест Б1", 100) не пустая Истина
Повторный вызов с ценой 999 — та же ссылка, цена 100 Истина
НайтиИлиСоздатьТовар(" ") пустая Истина

Ещё методы менеджера: НайтиПоРеквизиту(Имя, Значение), ПустаяСсылка(), СоздатьГруппу(). У документов: НайтиПоНомеру(Номер, Дата).

Ссылка

  • Хранит только вид объекта и идентификатор. Лежит в реквизитах других объектов: колонка Товар документа имеет тип СправочникСсылка.Товары.
  • Две ссылки на один товар равны, даже если найдены разными способами.
  • Каждое чтение Ссылка.Реквизит читает из базы весь объект. Для одного товара нормально, для сотен в цикле — медленно. Такое решают запросом (глава 3).
  • Пустая ссылка ни на что не указывает: ПолучитьОбъект() даст ошибку.
  • Битая указывает на удалённый объект: ПолучитьОбъект() вернёт Неопределено.

Объект

До Записать() После
ЭтоНовый() = Истина Ложь
Ссылка.Пустая() = Истина Ложь
Код пустой Присвоен при автонумерации
  • Заполнить из структуры: ЗаполнитьЗначенияСвойств(Объект, Структура).
  • Не записывай объект, если ничего не изменилось: каждая запись — обращение к базе и обработчики записи.
  • Табличная часть работает как таблица значений: Добавить, Удалить, Количество, Итог, НайтиСтроки, Выгрузить, Загрузить.
  • Проведение документа — глава 5.

Удаление

Способ Что происходит
УстановитьПометкуУдаления(Истина) Помечен, ссылки работают. Окончательно удаляют через «Все функции → Стандартные → Удаление помеченных объектов» с проверкой ссылок
Удалить() ⚠️ Удаляется сразу, остаются битые ссылки. Не использовать

Выборка

  • Справочники.Товары.Выбрать(), обход только Пока Выборка.Следующий() Цикл.
  • Доступны реквизиты, Выборка.Ссылка, Выборка.ПолучитьОбъект().
  • Нужен отбор или сортировка — запрос (глава 3).
