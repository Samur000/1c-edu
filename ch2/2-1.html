0. Подготовка: обработка «Песочница»

Песочница — обработка с одной кнопкой. Нажимаешь кнопку — выполняется твой код, результат выводится сообщениями. Она понадобится на всю главу 2 и главу 3.

Шаг 1. Создай обработку

  1. В навигаторе: правой кнопкой по «Обработки» → «Создать».
  2. Имя: Песочница. Синоним заполнится сам.

Шаг 2. Создай форму

  1. Открой обработку, внизу редактора — вкладка «Формы».
  2. Добавь новую форму. Тип — форма обработки. Отметь, что она основная.

Шаг 3. Добавь команду и кнопку

  1. В редакторе формы найди вкладку «Команды» и добавь команду ЗапуститьКод. Заголовок — «Запустить».
  2. В свойствах команды, в поле «Действие», создай обработчик: EDT предложит создать процедуру в модуле формы.
  3. Перетащи команду на форму — появится кнопка.

⚠️ Не называй команду Выполнить: Выполнить — встроенный оператор языка, будет конфликт имён.

Шаг 4. Напиши код модуля формы

КонецПроцедуры

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

    // Сюда пишешь код заданий.
    Сообщить("Песочница работает!");

КонецПроцедуры

#КонецОбласти

Что тут происходит:

  • &НаКлиенте и &НаСервере — директивы компиляции: где выполняется процедура. Кнопку нажимают на клиенте, а код заданий мы выполняем на сервере: в главе 3 там будут запросы к базе, а они работают только на сервере. Подробно — в главе 4.
  • Сообщить(...) выводит сообщение внизу формы. В типовых конфигурациях вместо него используют ОбщегоНазначения.СообщитьПользователю из БСП, но БСП в нашем проекте нет, поэтому для учёбы Сообщить в самый раз.

Шаг 5. Добавь Песочницу в интерфейс

Открой обработку → вкладка «Подсистемы» → отметь подсистему «Товары». Потом можно будет вынести её в отдельную подсистему «Разработка».

Шаг 6. Проверь

Нажми ▶, найди Песочницу в разделе «Товары», нажми «Запустить» — внизу должно появиться «Песочница работает!». Закоммить: Добавлена обработка Песочница.

Полезное в EDT

  • Автодополнение — Ctrl + Пробел. ⚠️ На Маке это же сочетание по умолчанию переключает раскладку. Если подсказки не появляются, отключи сочетание в «Системные настройки → Клавиатура → Сочетания клавиш → Источники ввода» или переназначь его в EDT.
  • Шаблоны: набери Если и вызови автодополнение — EDT вставит каркас Если … Тогда … КонецЕсли. Так же работает с Для, Пока, Процедура, Функция.
  • Справка: наведи курсор на функцию — появится описание из синтакс-помощника.
  • Переход к определению: Cmd + клик по имени процедуры.

1. Общие правила синтаксиса

Правило В 1С В JS
Регистр букв ⚠️ Не важен: СООБЩИТЬ, сообщить и Сообщить — одно и то же. Пишут как в стандарте: каждое слово с заглавной Важен
Конец оператора ; разделяет операторы ; необязателен
Комментарий // до конца строки. Многострочных комментариев нет // и /* */
Объявление переменной ⚠️ Не нужно: переменная появляется при первом присваивании let, const
Константы Нет const
Ключевые слова Русские или английские (Если = If). В стандартах — русские Английские
Блоки Ключевыми словами: Если … КонецЕсли, Цикл … КонецЦикла Фигурными скобками

bsl

// Переменная создаётся присваиванием, тип заранее не указывается.
Количество = 5;
Количество = "пять"; // можно, но так делать не надо: путает читателя

⚠️ Обращение к переменной, которой ещё ничего не присвоили, — ошибка «Переменная не определена». В JS было бы undefined, а здесь программа упадёт.

Переменные модуля объявляются в начале модуля через Перем. Стандарты советуют обходиться без них: передавай данные через параметры. В учебных заданиях Перем не используй.

2.1. Число

bsl

Цена = 99.99;
Количество = 3;
Сумма = Цена * Количество;        // 299.97
Целое = Цел(7 / 2);               // 3 — отбросить дробную часть

  • Деньги округляй через Окр(Значение, 2).

2.2. Строка

bsl

Имя = "Ноутбук";
Текст = "Товар: " + Имя;                    // склейка через +
Кавычки = "Модель ""Pro"" 2026";            // кавычка внутри строки удваивается
ПереводСтроки = "Строка 1" + Символы.ПС + "Строка 2";

Самые нужные функции:

Функция Что делает Пример → результат
СтрДлина(Стр) Длина СтрДлина("Кот") → 3
СокрЛП(Стр) Убрать пробелы по краям СокрЛП(" кот ") → "кот"
ВРег(Стр), НРег(Стр) Верхний или нижний регистр ВРег("кот") → "КОТ"
Лев(Стр, N), Прав(Стр, N) N символов слева или справа Лев("Привет", 3) → "При"

СтрНайти(Стр, Подстрока) ⚠️ Позиция с 1, 0 — если не нашлось СтрНайти("Привет", "в") → 4

СтрШаблон удобнее склейки через +, когда в строку подставляется несколько значений:

bsl

// Хуже: легко ошибиться с пробелами
Текст = "Товар " + Имя + ": " + Строка(Количество) + " шт.";
// Лучше:
Текст = СтрШаблон("Товар %1: %2 шт.", Имя, Количество);

2.3. Дата

Дата в 1С всегда хранит дату и время. Литерал — в одинарных кавычках в формате ГГГГММДД или ГГГГММДДччммсс.

bsl

ДатаНачала = '20261001';                  // 1 октября 2026, 00:00:00
ДатаСобытия = Дата(2026, 10, 12, 15, 30, 0);
Сегодня = ТекущаяДатаСеанса();            // текущая дата с учётом часового пояса сеанса

ЗавтраВЭтоЖеВремя = Сегодня + 86400;      // ⚠️ + число = + СЕКУНДЫ
РазницаВСекундах = Сегодня - ДатаНачала;  // дата − дата = секунды
РазницаВДнях = Цел(РазницаВСекундах / 86400);
Функция Что делает
Год(Дата), Месяц(Дата), День(Дата) Части даты числом
ДеньНедели(Дата) День недели: 1 — понедельник, 7 — воскресенье
НачалоДня(Дата), КонецДня(Дата) Начало и конец дня
НачалоМесяца(Дата), КонецМесяца(Дата) Начало и конец месяца
ДобавитьМесяц(Дата, N) Плюс N месяцев (N может быть отрицательным)
Формат(Дата, "ДФ=dd.MM.yyyy") Дата строкой в нужном виде
  • Пустая дата — '00010101'. Так выглядит незаполненное поле даты.
  • В конфигурациях используют ТекущаяДатаСеанса(), а не ТекущаяДата(): первая учитывает часовой пояс пользователя.

2.6. Универсальная проверка: ЗначениеЗаполнено

bsl

    Сообщить("Не заполнено наименование");
КонецЕсли;

ЗначениеЗаполнено возвращает Ложь для пустых значений любого типа: 0, пустой строки, пустой даты, Неопределено, Null, пустой ссылки на справочник. Это главный способ проверить, заполнено ли поле.

2.7. Проверка и преобразование типов

bsl

Значение = 42;

    Сообщить("Это число");
КонецЕсли;

ЧислоИзСтроки = Число("123.45");   // 123.45; Число("абв") — ошибка

3. Операторы

Что 1С JS
Арифметика + - * / % то же
Присваивание = =
Сравнение ⚠️ = (тот же символ!), <>, <, >, <=, >= ===, !==
Логика И, ИЛИ, НЕ &&, `
Тернарный ?(Условие, ЕслиДа, ЕслиНет) условие ? а : б
Инкремент ⚠️ Нет: пиши Счетчик = Счетчик + 1 ++, +=
  • Что значит = — присваивание или сравнение — понятно из контекста: в начале оператора это присваивание, внутри выражения — сравнение.
  • Логические выражения вычисляются сокращённо: если результат уже понятен по левой части, правая не вычисляется. Это используют для безопасных проверок:

bsl

// Если Количество = 0, деление не выполнится — ошибки не будет.
Если Количество <> 0 И Сумма / Количество > 100 Тогда
    Сообщить("Дорогой товар");
КонецЕсли;
  • Приоритет логических операторов: сначала НЕ, потом И, потом ИЛИ. Если сомневаешься — ставь скобки.

Тернарный оператор:

bsl

Статус = ?(Количество > 0, "В наличии", "Нет в наличии");

Удобен для коротких выражений. Если условие сложное, пиши обычный Если — так читаемее.

4. Условия

bsl

    Статус = "Нет в наличии";

    Статус = "Мало";

    Статус = "Достаточно";

  • Тогда обязательно после условия, КонецЕсли; — в конце блока.

  • Пиши условие в утвердительной форме, если это не усложняет: Если ЕстьОшибки Тогда читается лучше, чем Если Не НетОшибок Тогда.

5. Циклы

5.1. Для … По … — цикл со счётчиком

bsl

    Сообщить(СтрШаблон("Строка %1", Номер));

6. Процедуры и функции

Процедура Функция
Возвращает значение Нет Да, через Возврат Значение;
Можно в выражении Нет Да
Аналог в JS Функция без return Функция с return

bsl

Процедура ВывестиПриветствие(Имя)
    Сообщить("Привет, " + Имя + "!");
КонецПроцедуры

Функция Квадрат(Значение)
    Возврат Значение * Значение;
КонецФункции

// Вызов:
ВывестиПриветствие("Самур");
Результат = Квадрат(4);   // 16

Что важно:

  • Возврат в функции возвращает значение и сразу завершает её. В процедуре пишется без значения: Возврат;— просто досрочный выход.
  • Если функция дошла до конца без Возврат, она вернёт Неопределено. Так лучше не делать: каждая ветка функции должна явно возвращать значение.
  • Функцию можно вызвать как процедуру — результат просто отбросится. Процедуру в выражении использовать нельзя.
  • Порядок объявления в модуле не важен: процедуру можно вызвать выше, чем она написана.
  • Экспорт после списка параметров делает процедуру доступной из других модулей. Без него она видна только внутри своего модуля, как неэкспортированная функция в JS-модуле.
  • Переменные внутри процедуры — локальные: снаружи их не видно.

bsl

7. Параметры по ссылке и «Знач» — главное отличие от JS

7.1. Правило

⚠️ В 1С параметры по умолчанию передаются по ссылке: если внутри процедуры присвоить параметру новое значение, изменится и переменная в месте вызова. Даже если это число или строка. В JS примитивы всегда копируются — здесь не так.

Ключевое слово Знач перед параметром включает передачу по значению: процедура получает копию, и присваивание внутри не влияет на вызывающего.

bsl

Процедура УдвоитьПоСсылке(Значение)
    Значение = Значение * 2;
КонецПроцедуры

Процедура УдвоитьПоЗначению(Знач Значение)
    Значение = Значение * 2;
КонецПроцедуры

А = 10;
УдвоитьПоСсылке(А);
Сообщить(А);    // 20 — переменная А изменилась!

Б = 10;
УдвоитьПоЗначению(Б);
Сообщить(Б);    // 10 — не изменилась

7.2. Знач и коллекции — тонкий момент

Когда передаёшь массив, структуру или объект, в переменной лежит ссылка на коллекцию. Знач копирует саму ссылку, но не коллекцию. Поэтому:

  • изменения содержимого (добавить или удалить элемент) видны снаружи и с Знач, и без него;
  • присваивание параметру новой коллекции видно снаружи только без Знач.

bsl

Процедура ИзменитьСписок(Знач Список)
    Список.Добавить("новый элемент"); // ВИДНО снаружи: та же коллекция
    Список = Новый Массив;            // НЕ видно снаружи: Знач защитил переменную
КонецПроцедуры

Это как в JS с объектами: внутри функции можно поменять поля переданного объекта, но присваивание параметру новой ссылки наружу не попадёт.

7.3. Когда писать Знач

  • Почти всегда для входных параметров. Процедура не должна неожиданно портить переменные того, кто её вызвал. Это хорошая практика, и в типовых конфигурациях входные параметры обычно объявлены с Знач.
  • Без Знач — только если параметр специально задуман как выходной, то есть процедура должна вернуть через него результат. Но чаще лучше сделать функцию, которая возвращает значение: так понятнее, что откуда берётся.
  • В клиент-серверных вызовах у Знач есть ещё и практический смысл: параметр, переданный по ссылке при вызове сервера с клиента, после вызова передаётся обратно на клиент, а это лишний трафик. Подробно — в главе 4.

8. Оформление кода по стандартам

Имена

  • Слитно, каждое слово с заглавной: СуммаСНДС, КоличествоНаСкладе.
  • Без префиксов типа (стрИмя, масТовары), без подчёркивания в начале.
  • Однобуквенные — только счётчики циклов. Но и там лучше осмысленно: Номер, Индекс.
  • Флаги — как истинное значение: ЕстьОшибки, ЭтоУслуга.
  • Процедуры и функции — с глагола: РассчитатьСумму, ПроверитьИНН.
  • ⚠️ Не называй переменные именами встроенных функций и типов: Число, Строка, Дата, Тип, Выполнить.

Параметры

  • Не больше семи, из них необязательных — не больше трёх, необязательные — в конце.
  • Не вкладывай вызов одной функции в параметры другой: сначала результат в переменную.

Для месяцев есть отдельная функция ДобавитьМесяц. </details> <details><summary>10. Почему условие «Если Количество <> 0 И Сумма / Количество > 100» не упадёт при нулевом количестве?</summary> Логические выражения вычисляются сокращённо: если левая часть И ложна, правая уже не вычисляется, и деления на ноль не будет. </details> <details><summary>11. Почему переменную нельзя назвать «Строка»?</summary> Это имя встроенной функции и типа. Код станет непонятным, а проверка стандартов в EDT выдаст замечание. </details> <details><summary>12. Почему в конфигурациях используют ТекущаяДатаСеанса, а не ТекущаяДата?</summary> ТекущаяДатаСеанса учитывает часовой пояс сеанса пользователя, а ТекущаяДата берёт время компьютера, на котором выполняется код. </details>
