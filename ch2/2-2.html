2.2 Коллекции: массив, структура, соответствие, таблица значений

Уровень: 🔥 ключевое. С коллекциями ты будешь работать каждый день: результат запроса — таблица значений, параметры и результаты функций — структуры, справочники «ключ → значение» — соответствия. Где практикуемся: часть А — в Песочнице, часть Б — в общих модулях проекта Uchebnaya. Git: перед началом создай ветку feature/ch2-t2-kollekcii.

Как работать с конспектом

  • Обязательно прочитать: разделы 0–5 и всё, что помечено ⚠️.
  • Справочник: разделы 6–8. Открывай, когда застрял.
  • Практика: А1, А2, А4 и вся часть Б обязательны, А3 — по желанию.
  • Отличия от JavaScript помечены ⚠️.

⚠️ Всё проверяй запуском. Если что-то расходится с синтакс-помощником (раздел «Универсальные коллекции значений») — прав синтакс-помощник.

0. Какую коллекцию выбрать

Что нужно Коллекция Аналог в JS
Список значений по порядку Массив Array
Несколько именованных значений: параметры, результат функции Структура объект {}
Словарь: найти значение по ключу любого типа Соответствие Map
Таблица: строки и колонки, поиск, сортировка, итоги Таблица значений массив объектов + lodash

Где доступны:

  • Массив, структура, соответствие — и на клиенте, и на сервере.
  • ⚠️ Таблица значений — только на сервере. На тонком и веб-клиенте этого типа нет. Поэтому в модулях КлиентСервер вместо таблицы используют массив структур, а таблицу значений — в серверном коде. Реквизит формы с типом «(ТаблицаЗначений)» на самом деле другой тип, ДанныеФормыКоллекция, — это глава 4.

1. Массив

Товары = Новый Массив;                  // пустой массив
Товары.Добавить("Ноутбук");             // в конец
Товары.Добавить("Мышь");
Товары.Вставить(0, "Монитор");          // по индексу, остальные сдвигаются вправо

Первый = Товары[0];                     // "Монитор": индексы с 0, как в JS
Товары[1] = "Ноутбук Pro";              // замена по индексу
Всего = Товары.Количество();            // 3
Последний = Товары[Товары.ВГраница()];  // ВГраница — индекс последнего элемента

Товары.Удалить(0);                      // по индексу, остальные сдвигаются влево
Товары.Очистить();                      // удалить всё
Метод Что делает
Добавить(Значение) Добавляет в конец
Вставить(Индекс, Значение) Вставляет по индексу, остальные сдвигаются
Массив[Индекс] или Получить(Индекс) Читает элемент. ⚠️ Индекс за границей — ошибка
Массив[Индекс] = … или Установить(Индекс, Значение) Заменяет элемент
Удалить(Индекс) Удаляет, остальные сдвигаются
Найти(Значение) ⚠️ Индекс первого совпадения или Неопределено, а не -1
Количество() Число элементов
ВГраница() Индекс последнего элемента. ⚠️ У пустого массива -1
Очистить() Удаляет все элементы

Новый Массив(3) создаёт массив из трёх элементов со значением Неопределено.

Обход

// По элементам — когда индекс не нужен
Для Каждого Товар Из Товары Цикл
    Вывести(Товар);
КонецЦикла;

// По индексам — когда нужен номер
Для Индекс = 0 По Товары.ВГраница() Цикл
    Вывести(СтрШаблон("%1. %2", Индекс + 1, Товары[Индекс]));
КонецЦикла;

У пустого массива ВГраница() равна -1, поэтому цикл «от 0 до -1» просто не выполнится — ошибки не будет.

⚠️ Удаление по условию — с конца

Удаление сдвигает все следующие элементы. Если идти с начала, элемент после удалённого окажется на месте удалённого и будет пропущен, а в конце цикл выйдет за границу массива. При обходе с конца сдвигаются только уже проверенные элементы.

Индекс = Числа.ВГраница();
Пока Индекс >= 0 Цикл
    Если Числа[Индекс] < 0 Тогда
        Числа.Удалить(Индекс);
    КонецЕсли;
    Индекс = Индекс - 1;
КонецЦикла;

Строка ↔ массив

Части = СтрРазделить("Ноутбук,Мышь,,Монитор", ",");        // 4 элемента: третий — пустая строка
Части = СтрРазделить("Ноутбук,Мышь,,Монитор", ",", Ложь);  // 3 элемента: пустые выброшены
Текст = СтрСоединить(Части, ", ");                          // "Ноутбук, Мышь, Монитор"
  • Третий параметр СтрРазделить — включать ли пустые строки. По умолчанию включает.
  • СтрСоединить ожидает массив строк: числа сначала превращай в строки.
  • СтрСоединить — готовое решение задания А5 из задачи 1: запятая между элементами, без лишней в конце.

Фиксированный массив

Новый ФиксированныйМассив(Массив) — копия, которую нельзя изменить: нет Добавить, Удалить и т.д. Используют, чтобы защитить данные от случайной порчи. Пока просто знай, что такое есть.

2. Структура

// Пустая, ключи добавляем по одному
Товар = Новый Структура;
Товар.Вставить("Наименование", "Ноутбук");
Товар.Вставить("Цена", 60000);

// Сразу с ключами и значениями: ключи одной строкой через запятую, значения — следующими параметрами
Товар = Новый Структура("Наименование, Цена, Количество", "Ноутбук", 60000, 2);

// Только ключи — значения будут Неопределено
Отбор = Новый Структура("Склад, Товар");

Вывести(Товар.Цена);            // через точку — основной способ
Вывести(Товар["Цена"]);         // через скобки — когда имя ключа лежит в переменной
Товар.Цена = 55000;             // изменить существующий ключ
Товар.Вставить("Цена", 50000);  // Вставить: изменит, если ключ есть, и добавит, если нет

Правила ключей:

  • Ключ — только строка по правилам имён переменных: буквы, цифры и _, не начинается с цифры, без пробелов. "1Цена" или "Код товара" вызовут ошибку.
  • ⚠️ Регистр ключа не важен: Товар.цена и Товар.Цена — одно и то же.
  • ⚠️ Обращение к несуществующему ключу — ошибка, а не undefined, как в JS. Проверяй через Свойство:
Скидка = 0;
Если Товар.Свойство("Скидка") Тогда
    Скидка = Товар.Скидка;
КонецЕсли;

У Свойство есть и второй параметр, в который сразу кладётся найденное значение. Посмотри его в синтакс-помощнике.

Метод Что делает
Вставить(Ключ, Значение) Добавляет ключ или меняет значение существующего
Свойство(Ключ) Истина, если ключ есть
Удалить(Ключ) Удаляет ключ. Несуществующий ключ — без ошибки
Количество(), Очистить() Число элементов, удалить всё

Обход

Для Каждого КлючИЗначение Из Товар Цикл
    Вывести(СтрШаблон("%1 = %2", КлючИЗначение.Ключ, КлючИЗначение.Значение));
КонецЦикла;

⚠️ Не полагайся на порядок обхода: платформа его не гарантирует.

Главное применение — вернуть из функции несколько значений

Функция ИтогиСтроки(Знач Количество, Знач Цена)
    Результат = Новый Структура("Сумма, СуммаСоСкидкой");
    Результат.Сумма = Количество * Цена;
    Результат.СуммаСоСкидкой = Результат.Сумма * 0.9;
    Возврат Результат;
КонецФункции

Ещё структуры используют как набор параметров и как отбор для поиска в таблице значений (раздел 5.3).

3. Соответствие

ЦеныТоваров = Новый Соответствие;
ЦеныТоваров.Вставить("Ноутбук", 60000);
ЦеныТоваров["Мышь"] = 500;               // так тоже можно добавить или изменить

Цена = ЦеныТоваров["Ноутбук"];           // 60000
Цена = ЦеныТоваров.Получить("Принтер");  // Неопределено — без ошибки
  • Ключ любого типа: число, дата, строка с пробелами, ссылка на элемент справочника. В реальном коде самый частый случай — ссылка: «товар → цена», «сотрудник → оклад».
  • ⚠️ Нет ключа — вернётся Неопределено, ошибки не будет.
  • Удалить(Ключ), Количество(), Очистить() — как у структуры. Обход — тоже через КлючИЗначение.
  • ⚠️ Порядок обхода не гарантирован.

Типовой приём — убрать дубли

Ключи соответствия уникальны: вставка существующего ключа просто перезапишет значение.

Уникальные = Новый Соответствие;
Для Каждого Товар Из Товары Цикл
    Уникальные.Вставить(Товар, Истина);
КонецЦикла;
// Теперь ключи Уникальные — товары без повторов

4. Структура или соответствие

Структура Соответствие
Тип ключа Строка по правилам имён Любой
Доступ .Ключ и ["Ключ"] [Ключ] и Получить(Ключ)
Нет ключа ⚠️ Ошибка → проверяй Свойство() Неопределено
Регистр строкового ключа Не важен Проверишь в задании А2
Когда использовать Набор полей известен заранее Ключи приходят из данных

Простое правило: если ключи пишешь в коде руками (Цена, Количество) — структура. Если ключи берутся из данных (коды, слова, товары) — соответствие.

5. Таблица значений 🔥

5.0. Что это такое

Таблица значений — это таблица в памяти: колонки заданы заранее, строки добавляешь сколько нужно. По сути, лист Excel внутри кода.

Товар Склад Количество Сумма
Ноутбук Основной 2 120000
Мышь Основной 10 5000
Монитор Дальний 3 45000

Аналог в JavaScript — массив объектов с одинаковыми полями:

const sales = [
  { product: "Ноутбук", store: "Основной", qty: 2, sum: 120000 },
  { product: "Мышь", store: "Основной", qty: 10, sum: 5000 },
];

Отличия от массива объектов:

  • колонки объявляются заранее, у каждой может быть тип;
  • поиск, сортировка, группировка и суммы уже встроены как методы — не нужно писать filter, sort, reduce.

⚠️ Таблица значений есть только на сервере. На клиенте её нет, поэтому в модулях КлиентСервер вместо неё используют массив структур.

5.1. Создание и колонки

Продажи = Новый ТаблицаЗначений;
Продажи.Колонки.Добавить("Товар", Новый ОписаниеТипов("Строка"));
Продажи.Колонки.Добавить("Склад", Новый ОписаниеТипов("Строка"));
Продажи.Колонки.Добавить("Количество", Новый ОписаниеТипов("Число"));
Продажи.Колонки.Добавить("Сумма", Новый ОписаниеТипов("Число", Новый КвалификаторыЧисла(15, 2)));

Первый параметр — имя колонки, второй — её тип. КвалификаторыЧисла(15, 2) — 15 знаков, из них 2 после запятой: стандарт для денег.

Зачем указывать тип. В колонке без типа у новой строки значение Неопределено, а в числовой — 0, в строковой — пустая строка. С типизированными колонками сортировка, свёртка и итоги работают предсказуемо. Правило: колонки, по которым считаешь или сортируешь, всегда типизируй.

Продажи.Колонки.Найти("Склад") вернёт колонку или Неопределено, если её нет.

5.2. Добавление строк

Добавить() создаёт одну новую пустую строку и возвращает её. Дальше заполняешь колонки через точку.

НоваяСтрока = Продажи.Добавить();
НоваяСтрока.Товар = "Ноутбук";
НоваяСтрока.Склад = "Основной";
НоваяСтрока.Количество = 2;
НоваяСтрока.Сумма = 120000;

НоваяСтрока = Продажи.Добавить();   // ⚠️ для каждой строки — снова Добавить()
НоваяСтрока.Товар = "Мышь";
НоваяСтрока.Склад = "Основной";
НоваяСтрока.Количество = 10;
НоваяСтрока.Сумма = 5000;

⚠️ Частая ошибка: вызвать Добавить() один раз, а потом заполнять несколько «строк». На самом деле перезаписывается одна и та же строка, и в таблице останется только последняя.

Короче — через структуру. ЗаполнитьЗначенияСвойств(Приемник, Источник) копирует значения свойств с одинаковыми именами:

Данные = Новый Структура("Товар, Склад, Количество, Сумма", "Монитор", "Дальний", 3, 45000);
ЗаполнитьЗначенияСвойств(Продажи.Добавить(), Данные);

Ещё короче — вспомогательная процедура. Когда строк много, вынеси добавление в процедуру и вызывай одной строкой:

&НаСервере
Процедура ДобавитьПродажу(Таблица, Знач Товар, Знач Склад, Знач Количество, Знач Сумма)
    НоваяСтрока = Таблица.Добавить();
    НоваяСтрока.Товар = Товар;
    НоваяСтрока.Склад = Склад;
    НоваяСтрока.Количество = Количество;
    НоваяСтрока.Сумма = Сумма;
КонецПроцедуры

// Вызов:
ДобавитьПродажу(Продажи, "Ноутбук", "Основной", 2, 120000);
ДобавитьПродажу(Продажи, "Мышь", "Основной", 10, 5000);

Таблица здесь без Знач: процедура должна изменить таблицу, которую ей передали.

5.3. Обход и чтение строк

Основной способ — Для Каждого по строкам. На каждой итерации переменная цикла — это очередная строка таблицы, и у неё через точку доступны все колонки:

Для Каждого СтрокаПродаж Из Продажи Цикл
    Вывести(СтрШаблон("%1 — %2 шт. — %3 руб.", СтрокаПродаж.Товар, СтрокаПродаж.Количество, СтрокаПродаж.Сумма));
КонецЦикла;

Результат:

Ноутбук — 2 шт. — 120 000 руб.
Мышь — 10 шт. — 5 000 руб.
Монитор — 3 шт. — 45 000 руб.

⚠️ Не называй переменную цикла Строка — это имя встроенной функции. Пиши СтрокаПродаж, ТекущаяСтрока или по смыслу: Сотрудник, Товар.

Количество строк:

Вывести(Продажи.Количество()); // 3

Строка по номеру — как элемент массива, индексы с 0:

ПерваяСтрока = Продажи[0];
Вывести(ПерваяСтрока.Товар);    // "Ноутбук"

ПоследняяСтрока = Продажи[Продажи.Количество() - 1];

Обход по индексам — когда нужен номер строки:

Для Индекс = 0 По Продажи.Количество() - 1 Цикл
    Вывести(СтрШаблон("%1. %2", Индекс + 1, Продажи[Индекс].Товар));
КонецЦикла;

Колонка по имени из переменной — через квадратные скобки:

ИмяКолонки = "Сумма";
Вывести(ПерваяСтрока[ИмяКолонки]);   // то же, что ПерваяСтрока.Сумма

Обход колонок. Если нужно вывести строку целиком, не перечисляя колонки вручную, обойди коллекцию Колонки:

Для Каждого СтрокаПродаж Из Продажи Цикл
    Части = Новый Массив;
    Для Каждого Колонка Из Продажи.Колонки Цикл
        Части.Добавить(Строка(СтрокаПродаж[Колонка.Имя]));
    КонецЦикла;
    Вывести(СтрСоединить(Части, " | "));
КонецЦикла;

Так работает любой универсальный вывод: код не знает заранее, какие в таблице колонки.

5.4. Изменение строк

Строка, которую даёт цикл, — это сама строка таблицы, а не копия. Присвоил значение — изменилась таблица:

Для Каждого СтрокаПродаж Из Продажи Цикл
    СтрокаПродаж.Сумма = СтрокаПродаж.Сумма * 1.1;   // поднять все суммы на 10%
КонецЦикла;

5.5. Поиск

Найти — первая подходящая строка или Неопределено:

НайденнаяСтрока = Продажи.Найти("Мышь", "Товар");
Если НайденнаяСтрока <> Неопределено Тогда
    Вывести(НайденнаяСтрока.Сумма);
КонецЕсли;

⚠️ Вторым параметром указывай колонку. Без него поиск идёт по всем колонкам.

НайтиСтроки — все строки по отбору. Отбор — структура «колонка = значение», результат — массив строк:

Отбор = Новый Структура("Склад", "Основной");
СтрокиОсновного = Продажи.НайтиСтроки(Отбор);
Вывести(СтрокиОсновного.Количество());

Для Каждого СтрокаПродаж Из СтрокиОсновного Цикл
    Вывести(СтрокаПродаж.Товар);
КонецЦикла;
  • ⚠️ НайтиСтроки возвращает сами строки таблицы, а не копии. Изменишь строку из этого массива — изменится исходная таблица.
  • В отборе можно указать несколько колонок: Новый Структура("Склад, Товар", "Основной", "Мышь").
  • НайтиСтроки ищет только по равенству. Для «больше» или «меньше» — цикл с Если, а в реальных задачах — запрос (глава 3).

5.6. Новая таблица из части данных — Скопировать

Копия = Продажи.Скопировать();                                         // полная копия
ДальнийСклад = Продажи.Скопировать(Новый Структура("Склад", "Дальний"));  // только строки по отбору
ТоварыИСуммы = Продажи.Скопировать(, "Товар, Сумма");                  // все строки, только две колонки
Пустая = Продажи.СкопироватьКолонки();                                 // те же колонки, без строк

Первый параметр — отбор (структура) или массив строк, например результат НайтиСтроки. Второй — какие колонки взять. Исходная таблица не меняется.

5.7. Сортировка

Продажи.Сортировать("Сумма Убыв");
Продажи.Сортировать("Склад, Сумма Убыв");  // сначала по складу, внутри склада — по сумме

По умолчанию по возрастанию (Возр). ⚠️ Сортируется сама таблица.

5.8. Свёртка — группировка с суммированием

Продажи.Свернуть("Товар", "Количество, Сумма");

Первый параметр — по каким колонкам группировать, второй — какие суммировать. Аналог GROUP BY с SUM в SQL.

Было:

Товар Склад Количество Сумма
Мышь Основной 10 5000
Мышь Дальний 4 2000
Ноутбук Основной 2 120000

Стало:

Товар Количество Сумма
Мышь 14 7000
Ноутбук 2 120000

⚠️ Две ловушки:

  • все остальные колонки удаляются — колонки Склад после свёртки нет;
  • меняется сама таблица. Если исходная ещё нужна — сначала Скопировать(), потом сворачивай копию.

Без второго параметра получишь уникальные значения колонок группировки: Продажи.Свернуть("Товар") оставит список товаров без повторов.

5.9. Итоги и колонки целиком

ВсегоСумма = Продажи.Итог("Сумма");                 // сумма по колонке
СписокТоваров = Продажи.ВыгрузитьКолонку("Товар");  // массив значений одной колонки
Продажи.ЗагрузитьКолонку(НовыеСуммы, "Сумма");      // обратно: из массива в колонку
Продажи.ЗаполнитьЗначения(0, "Сумма");              // одно значение во все строки колонки

ВыгрузитьКолонку нужна, когда значения одной колонки нужны отдельным массивом, например чтобы склеить их через СтрСоединить. Для обхода таблицы она не нужна — для этого Для Каждого (5.3).

5.10. Удаление строк

Продажи.Удалить(НайденнаяСтрока);  // по строке
Продажи.Удалить(0);                // по индексу
Продажи.Очистить();                // все строки, колонки остаются

⚠️ Не удаляй строки внутри Для Каждого по самой таблице — строки будут пропускаться. Два безопасных способа:

1. Обход с конца по индексам:

Индекс = Продажи.Количество() - 1;
Пока Индекс >= 0 Цикл
    Если Продажи[Индекс].Количество = 0 Тогда
        Продажи.Удалить(Индекс);
    КонецЕсли;
    Индекс = Индекс - 1;
КонецЦикла;

2. Через НайтиСтроки: сначала найти строки, потом удалить каждую. Цикл идёт по отдельному массиву, а не по таблице:

ПустыеСтроки = Продажи.НайтиСтроки(Новый Структура("Количество", 0));
Для Каждого ПустаяСтрока Из ПустыеСтроки Цикл
    Продажи.Удалить(ПустаяСтрока);
КонецЦикла;

5.11. Индексы — для больших таблиц

Продажи.Индексы.Добавить("Склад, Товар");

Ускоряют Найти и НайтиСтроки на больших таблицах. По стандарту 1С (std452) индекс стоит добавлять, если в большой таблице ищешь два раза и больше, причём поля индекса должны совпадать с полями отбора. На учебных таблицах из десятка строк не нужны.

6. Общее для всех коллекций

Ссылочный тип

Как и в JS: присваивание копирует ссылку. Изменишь Копия — изменится Исходный. И Знач при передаче в процедуру защищает переменную, но не содержимое коллекции (задание А6 из задачи 1).

Как сделать настоящую копию

У массива, структуры и соответствия есть конструкторы «из фиксированной коллекции» — на этом и построен приём.

Прочее

  • Не меняй количество элементов коллекции внутри Для Каждого по ней же. Удаляй с конца или через отдельный массив.
  • Сравнение содержимого. Чтобы проверить, что в двух коллекциях одно и то же, сравнивай элементы или поля по отдельности. Что даёт обычное = для двух массивов — проверишь в А2.
  • Вложенность — норма: массив структур, структура с массивом внутри. Массив структур — клиент-серверная замена таблицы значений.

Часть Б. Сквозной проект

Б1. ЦенообразованиеКлиентСервер.ИтогиДокумента(СтрокиДокумента, СуммаВключаетНДС = Истина)

Считает итоги документа по его строкам. Пригодится в главе 4: форма документа будет показывать их в подвале.

  • Параметр СтрокиДокумента — массив структур с ключами Количество, Цена, СтавкаНДС.
  • Возвращает структуру с ключами Количество, Сумма, СуммаНДС, Всего.
  • Для каждой строки: сумма — через твою РассчитатьСумму, НДС — через РассчитатьСуммуНДС. Используй готовые функции, не дублируй формулы.
  • НДС округляется в каждой строке, а потом складывается — так считают документы 1С.
  • Всего: если НДС включён в сумму — Всего = Сумма; если нет — Сумма + СуммаНДС.
  • Пустой массив — все итоги равны нулю.

Почему массив структур, а не таблица значений: модуль клиент-серверный, а таблицы значений на клиенте нет.

Описание параметра-массива структур по стандарту выглядит так, EDT его понимает:

//   * Количество - Число - количество товара.
//   * Цена - Число - цена за единицу.
//   * СтавкаНДС - Число - ставка НДС в процентах.

Б2. СтрокиКлиентСервер.РазобратьПараметры(СтрокаПараметров)

Разбирает строку вида "ключ=значение; ключ=значение" в соответствие. Такие строки встречаются в настройках и при загрузке данных (глава 11).

  • Части разделены ;, ключ и значение — первым =. Значение само может содержать =.
  • У ключей и значений убери пробелы по краям (СокрЛП).
  • Пустые части и части без = пропускай.
  • Значения остаются строками.
  • Подсказка: позицию первого = даст СтрНайти, а части — Лев и Сред.

Почему соответствие, а не структура: ключи приходят из данных и могут быть с пробелами — например, «Код товара». Структура на таком ключе упадёт.

10. Вопросы для самопроверки

Сначала ответь сам, потом читай ответ.

1. Что вернёт Найти у массива, если значения нет?

Ответ: Неопределено, а не -1, как indexOf в JS.

2. Почему элементы по условию удаляют, обходя массив с конца?

Ответ: Удаление сдвигает следующие элементы влево. При обходе с начала элемент после удалённого будет пропущен, а цикл выйдет за границу. С конца сдвигаются только уже проверенные элементы.

3. Чему равна ВГраница() у пустого массива?

Ответ: -1. Поэтому цикл «Для Индекс = 0 По Массив.ВГраница()» на пустом массиве просто не выполнится.

4. Что будет при обращении к несуществующему ключу структуры? А соответствия?

Ответ: У структуры — ошибка, проверять нужно через Свойство(). У соответствия — вернётся Неопределено.

5. Когда выбрать структуру, а когда соответствие?

Ответ: Структура — когда набор полей известен заранее и ключи пишутся в коде. Соответствие — когда ключи приходят из данных или они не строковые: ссылки, числа, строки с пробелами.

6. Почему в модуле КлиентСервер нельзя использовать таблицу значений?

Ответ: Таблица значений доступна только на сервере, на тонком и веб-клиенте этого типа нет. Вместо неё используют массив структур.

7. Что делает Свернуть с колонками, которых нет в её параметрах?

Ответ: Удаляет их. И меняет саму таблицу, поэтому если исходные данные ещё нужны — сворачивают копию.

8. Чем Найти отличается от НайтиСтроки?

Ответ: Найти возвращает первую подходящую строку или Неопределено. НайтиСтроки возвращает массив всех строк, подходящих под отбор-структуру.

9. Изменил строку из результата НайтиСтроки. Изменится ли таблица?

Ответ: Да: НайтиСтроки возвращает сами строки таблицы, а не их копии.

10. Почему «Копия = Исходный» — не копия массива? Как сделать копию?

Ответ: Коллекции ссылочные: присваивание копирует ссылку, и обе переменные указывают на один массив. Копия: Новый Массив(Новый ФиксированныйМассив(Исходный)).

11. Как получить таблицу только со строками склада «Дальний», не трогая исходную?

Ответ: Таблица.Скопировать(Новый Структура("Склад", "Дальний")).

12. Зачем указывать типы колонок таблицы значений?

Ответ: В колонке без типа у новых строк Неопределено, а в типизированной — значение по умолчанию (0, пустая строка). Сортировка, свёртка и итоги по типизированным колонкам работают предсказуемо.
