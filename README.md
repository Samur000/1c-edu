# Конспекты 1С · путь до джуна

Конспекты по плану обучения 1С-разработчика: EDT и Git, встроенный язык, язык запросов, СКД и внешние отчёты, дальше — печатные формы, расширения, БСП, ЗГУ, обмены.

Каждая задача плана — отдельная страница: словарь, объяснение на учебных данных, шаги со скринами из EDT и 1С:Предприятия, ловушки, практика.

Сайт — обычные HTML-страницы без сборки. GitHub Pages отдаёт их как есть.

## Структура

```
index.html          главная: все главы и задачи плана, отметки «пройдено»
assets/
  plan.js           план: главы, задачи, режимы, ссылки на страницы
  site.css          оформление
  site.js           навигация, содержание, просмотр скринов, настройки
  boot.js           тема и настройки до отрисовки страницы
chN/
  N-M.html          конспект задачи N.M
  img/N-M/          скрины к этому конспекту
  files/            PDF и картинки их страниц
```

## Как добавить конспект

1. Страница `chN/N-M.html` по образцу соседних, скрины — в `chN/img/N-M/`.
2. В `assets/plan.js` у задачи указать `page: "chN/N-M.html"`.

Главная, навигация и ссылки на соседние конспекты обновятся сами.

## Посмотреть локально

```bash
python3 -m http.server 8765
```

и открыть `http://localhost:8765`.
